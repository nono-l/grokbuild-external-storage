# 計画: Hobby を超える人向けの自前ストレージ

## 前提（間違いやすい点）

Grok Build の Vercel デプロイには **DB が無いわけではない**。

- Neon Postgres（小さな行・認証・設定）
- Hobby の Blob など（カジュアル向けの小さい無料枠）

枠は **カジュアル / 個人が少し使える** 大きさ。無駄に大きく使うとすぐ埋まる。

## このキットの役割

Hobby を超えて使いたいユーザーに、

> それなら自分のストレージに保存してください

と言えるようにする **拡張**。プラットフォームの無料枠は温存する。

## 方針

- デフォルトは Vercel / Neon を小さく使う
- 溢れる分・長く残したい分だけ、ユーザー HTTPS + MySQL へ JSON
- アプリ差は `apps/{id}.php` だけ。プロキシは Grok Build 共通
- バイナリ（音声・動画）はどちらにも置かない
