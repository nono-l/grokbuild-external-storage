Grok Build · External Storage

HTTPS MySQL プロキシ

Vercel 上の Grok Build アプリ向けの共通コアです。顔（名前・CORS）は apps/active.php、 データは {appId}.{tenant} で分かれます。

install.php は OS のインストールメディア相当（API サーバー初期化）。 setup.php は入れた OS をどう使うかの運用設定です。

  • install.php — インストールメディア（DB・APIキー）
  • setup.php — 運用設定（接続後の IP・ログ）
  • api/proxy.php — JSON API
  • dlzip.php — 秘密マスク ZIP
